# やぎ座ノースノード — 実装原稿

実装担当者は、次の順序で原稿を参照してください。

1. [`top-page.md`](./top-page.md) — トップページに掲載する文章
2. [`chapters.md`](./chapters.md) — 本編全7章の完成原稿

`chapters.md` の各章は、次の3区分で構成されています。

- 原文に忠実な「本文を深く読む」
- 著者が示した「日々の実践」
- 編集による「本文から導く確認」

「本文から導く確認」とトップページ末尾の「日々、心に戻す言葉」は、著者の文章そのものではなく、本文の要点を実生活で確認するための編集文です。実装時も、この区別が読者に分かる注記を残してください。
